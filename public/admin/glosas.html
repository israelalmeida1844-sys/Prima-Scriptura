Editor de glosas gregas

Edição palavra por palavra, com histórico de alterações no GitHub e preservação do texto crítico.

As glosas são salvas na área de rascunhos, separada do site público. Você pode acumular quantas correções desejar e publicá-las juntas apenas quando clicar em Publicar alterações. O texto grego, o lema e a morfologia são preservados.

1. Autenticação

Conecte sua conta GitHub autorizada para carregar e salvar glosas.

A autenticação utiliza o serviço OAuth já configurado no Prima Scriptura. Não informe senhas ou tokens nesta página.

2. Localizar uma palavra

Faça login para iniciar.

Publicação sob seu controle

Entre para consultar as alterações em rascunho.

O botão de publicação reúne as alterações na ramificação principal. Confira as pendências antes de publicar.
